# tests/

Tests `node:test`, sans dépendance. Lancer : `node --test "tests/*.test.mjs"` (guillemets conservés).

- `systems.test.mjs` : validité de `systems.json` (schéma, ids uniques, amiga et neogeo complets).
- `serve.test.mjs` : serveur local (index.html, MIME, 404, Range, refus de `../`, noms de fichiers spéciaux, liens symboliques hors racine, nosniff) (T1, T11).
- `serve-port.test.mjs` : choix du port (`--port`, `PORT`, défaut 8080) et de l'hôte (`--host`, `HOST`) (T20).
- `generate-games.test.mjs` : générateur de `games.json` sur de faux fichiers temporaires (titres, .m3u, jaquettes, tri, cas limites).
- `actions.test.mjs` : clavier et manette vers actions, répétition, réveil de manette, boucle avec environnement factice (T4).
- `focus-nav.test.mjs` : navigation spatiale avec rectangles et éléments factices (T4).
- `data.test.mjs` : validation de `systems.json` et `games.json`, `loadData` avec `games.json` absent, encodage des chemins (T3).
- `router.test.mjs` : routes hash, `?focus=`, aller-retour, routeur avec fenêtre factice (T3).
- `sort.test.mjs` : tri des titres partagé (T3).
- `dom.test.mjs` : helpers `el` et `clear` avec document factice (T3).
- `machine-grid.test.mjs` : accueil (tuiles, 0 jeu en fin de liste, 12 machines, messages games.json, choix d'écran, rendu avec document factice) (T5).
- `game-grid.test.mjs` : grille de jeux (initiales, tuiles, focus de retour, état vide, repli de jaquette) et boîte de confirmation (T6).
- `launcher.test.mjs` : plan de lancement EmulatorJS (variables EJS_*, BIOS, chemins encodés), fichiers manquants, chargement avec fenêtre factice (T7).
- `virtual-stick.test.mjs` : joystick tactile, directions (zone morte, hystérésis, jamais deux opposées) et enveloppe de `nipplejs.create` (T32).
- `exit-guard.test.mjs` : sortie du jeu (F10, Échap maintenu, Select+Start), aucune autre touche captée (T7).
- `disk-shortcut.test.mjs` : raccourci disquette (Select+RB front montant, F9, cycle, jeu à 1 disquette, Select+Start exclu, anti-rebond) et `getDiskState`/`switchToDisk` (T12).
- `player-ui.test.mjs` : rappel de sortie, textes, anneau de progression, mode d'entrée (T7).
- `sw.test.mjs` : logique pure de `sw.js` (liste de la coquille complète, filtre : jamais roms/, bios/, games.json ni le CDN, nettoyage des caches) (T8).
- `pwa.test.mjs` : manifest, icônes PNG, liens dans les pages, enregistrement du service worker (T8).
- `generate-logos.test.mjs` : logos SVG (un par machine, valides, sans doublon, couleurs et contraste, fichiers à jour) (T5b).
- `retroarch-cfg.test.mjs` : lignes ajoutées au retroarch.cfg, raccourcis à nul, surcharge de `getRetroArchCfg` (T14).
- `ejs-start-watch.test.mjs` : détection d'un contenu refusé par le cœur, sans faux positif, hook de `EJS_Runtime` (T14).
- `version.test.mjs` : format de `js/version.js`, ticket à jour, libellé, cohérence avec `sw.js` et `pwa.js` (T16).
- `diagnostic-log.test.mjs`, `diagnostic-panel.test.mjs` : journal et panneau du mode `debug=1`, absent sans `debug=1` (T16).
- `disk-trace.test.mjs` : journal des changements de disquette (ok, unreachable puis ok, double échec et rétablissement, état 0,5/2/5 s), lignes du cœur, niveau de log selon debug (T16).
- `pages.test.mjs` : publication GitHub Pages, `.nojekyll` présent, jamais servi ni mis en cache, pas de nom en `_` (T17).
- `local-settings.test.mjs` : réglages `clone90.local.json` (lecture, validation, fusion) et générateur sur un `romsDir` choisi (T23).
- `serve-dossiers.test.mjs` : serveur avec `romsDir` et `biosDir` choisis, refus de sortie, réglage jamais servi (T23).
- `choisir-dossier-mac.test.mjs` : `Choisir le dossier des jeux.command` et lanceur (`bash -n`, bits exécutables) (T23).
- `launcher-mac.test.mjs` : lanceur Mac `Lancer Clone90.command` (contenu, `bash -n`, jamais servi ni mis en cache) (T20).
- `design.test.mjs` : design « Cartouche bleue » (palette, contrastes WCAG, couleur déclarée une seule fois, `prefers-reduced-motion` couvre les animations, clignotement 1 Hz, focus, logos/icônes/manifeste alignés sur `base.css`) (T24).
- `mac-app.test.mjs` : application Mac `Clone90.app` (source AppleScript, bundle, `bash -n` du script de construction, jamais servie ni mise en cache) (T26).
- `samples.test.mjs` : samples fbneo (plan de lancement Zaxxon avec et sans pack, Neo Geo, Amiga, validation de `samples`, liste blanche du serveur, service worker, générateur) (T22).
- `posix-path.test.mjs` : `js/posix-path.js` identique à `node:path` posix (T27).
- `local-library.test.mjs` : jouer sur téléphone sans le Mac (noms et chemins importés, BIOS au nom exact, IndexedDB factice, jeux locaux, fusion avec games.json, route `#/fichiers`, service worker sans cache, écran « Mes fichiers ») (T27).
- `settings-api.test.mjs` : API locale des dossiers (désactivée hors macOS ou réseau, Host, Origin, X-Clone90, Content-Type, 1 Ko, corps invalide, verrou, annulation, refus, vrai générateur) et boîte du Mac factice (T25).
- `player-layout.test.mjs` : page de jeu sur téléphone, barre du haut en portrait, ☰ d'EmulatorJS rangé dans la barre, 48 px (T28).
- `folders-panel.test.mjs` : client de l'API, panneau « Dossiers des jeux », bouton de l'accueil, boîte générique, `api/` jamais en cache (T25).
- `covers.test.mjs` : pochettes automatiques sans réseau (faux dépôts GitHub : correspondance, région, ambiguïté, caractères remplacés, pas d'écrasement, PNG vérifié, 2 Mo, dry-run, multi-disquettes, arcade, cache) (T28).
- `covers-api.test.mjs` : API locale des pochettes (sécurité identique à T25, 202 puis suivi, verrou partagé, erreurs) (T28).
- `machine-logos.test.mjs` : logos des machines sans réseau (adresse figée, SVG vérifié, scripts et liens refusés, pas d'écrasement, dossier des ROMs choisi, champ `logos` de games.json) (T29).
- `machine-logos-ui.test.mjs` : logos côté navigateur et serveur (`logoTheme`, validation de `logos`, repli logo téléchargé, logo maison, nom ; client, panneau, API et verrou partagé ; CSP des SVG) (T29).
- `link-finder.test.mjs` : analyse d'une page (adresse saisie, liens, extensions de systems.json, BIOS, machine devinée, contrôle d'un choix) (T34).
- `link-relay.test.mjs` : relais du Mac (adresses locales et privées refusées, DNS figé, redirections, tailles, écriture sûre) (T34).
- `links-api.test.mjs` : API `api/links...` (sécurité T25, corps validé, suivi, verrou partagé) (T34).
- `link-download.test.mjs` : sources Mac et navigateur (CORS refusé, « Mes fichiers »), aides de l'écran, route `#/telecharger` (T34).

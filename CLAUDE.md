## Le produit

Clone90 est un site web pour jouer aux jeux rétro des années 90 avec EmulatorJS, sur PC, Mac et Android.
On choisit une machine, puis un jeu dans une grille de grandes tuiles, et le jeu s'ouvre en plein écran.
Navigation à la souris, au tactile, au clavier et à la manette (Gamepad API). Installable en PWA.

## Stack technique

- HTML, CSS et JavaScript (modules ES) **sans framework et sans build**.
- EmulatorJS chargé depuis son CDN officiel, version dans une seule constante (`js/config.js`).
- Script Node.js **sans dépendance** : `scripts/generate-games.mjs` scanne `roms/` et produit `games.json`.
- Tests : `node:test` pour la logique (script, modules purs). Pas de dépendance npm sans accord.
- Hébergement : GitHub Pages (dépôt public), chemins **toujours relatifs**.

L'architecture détaillée est dans `docs/architecture.md`, l'interface dans `docs/ux.md`. Les lire avant de coder.

## Règles produit (non négociables)

1. **Aucune ROM ni BIOS dans le dépôt** (`roms/`, `bios/` et `games.json` sont ignorés par git). On ne fournit aucun jeu.
2. `systems.json` est la **seule source de vérité** des machines : aucune liste de machines écrite ailleurs.
3. Une seule couche d'entrée (`js/input/`) pour clavier, manette, tactile et souris.
4. Seul `js/player/launcher.js` connaît EmulatorJS.
5. Aucune statistique, aucun compte. Aucune donnée de l'utilisateur n'est envoyée sur le réseau. Seules exceptions : des lectures déclenchées uniquement par un clic ou une commande : (a) vers github.com, base libre libretro-thumbnails, par le bouton « Télécharger les pochettes » ou `node scripts/covers.mjs` (Mac), SANS clic sur le Mac à l'ouverture de Clone90 et après un ajout de jeux par Clone90 s'il reste des jeux sans pochette (T40), et dans « Mes fichiers » après un ajout de jeux ou par le bouton « Chercher les pochettes manquantes » (T40, navigateur) ; images seulement ; GitHub voit l'adresse IP et les noms des jeux cherchés ; (b) vers github.com, logos du thème es-theme-carbon (RetroPie), par le bouton « Télécharger les logos des machines » ou `node scripts/machine-logos.mjs`, et dans « Mes fichiers » avec la recherche des pochettes (T42, navigateur, une fois par machine) ; GitHub voit l'adresse IP, aucun nom de jeu ; (c) T34 : la page web dont la personne donne l'adresse dans l'écran « Depuis une page web », et les fichiers qu'elle y coche, lus seulement au clic (« Analyser », « Télécharger ») ; ce site voit l'adresse IP, rien d'autre n'est envoyé ; aucun site écrit dans le code ; (d) T35, SANS clic : à chaque ouverture de Clone90 sur le Mac (et, T47, au retour sur un onglet resté ouvert si la dernière vérification a 5 h ou plus), lecture de `js/version.js` de la branche main sur raw.githubusercontent.com (dépôt HnaoAI/Clone90, adresse fixe) pour savoir si une mise à jour existe, puis, s'il y en a une, `git pull` depuis ce même dépôt ; GitHub voit l'adresse IP, rien d'autre n'est envoyé ; (e) T43 : partage Mac -> téléphone sur le réseau local, jamais sur Internet : le Mac n'ouvre son serveur de partage (HTTPS, port 8443, lecture seule sauf l'ajout de jeux, pochettes et BIOS de T44 et T53) qu'après « Activer le partage », et ne sert les jeux, pochettes, logos et BIOS qu'aux téléphones associés par le mot de passe choisi sur le Mac (T51, à la place du code) ; le téléphone ne parle qu'à des adresses privées ou .local, en HTTPS, port 8443 : T51, pour trouver le Mac il interroge (`/sync/hello`, sans aucune donnée) sa dernière adresse, son nom .local, puis, à l'association ou sur « Synchroniser maintenant » seulement, les adresses 192.168.1.x, 192.168.0.x et le réseau de la dernière adresse ; sans clic à l'ouverture une fois associé (dernière adresse et nom .local seulement) ; T44 : au clic sur « Envoyer mes jeux au Mac », le téléphone envoie à ce Mac ses jeux, pochettes et (T53) BIOS (jamais les logos) que le Mac n'a pas, et le Mac ne les reçoit que si la personne a coché « Accepter les jeux du téléphone » (éteint par défaut), sans jamais remplacer un fichier.
6. Le service worker ne met jamais en cache les ROMs ni les BIOS. Seule ressource d'une autre origine qu'il garde : le moteur EmulatorJS de son CDN, versions x.y.z seulement, dans `clone90-ejs-<version>` (T46, jeu hors ligne).

# scripts/

Scripts Node.js sans dépendance (Node 18 ou plus récent).

- `serve.mjs` : serveur statique local (T25 : branche l'API des dossiers, `isSettingsApiEnabled`, `server.setFolders`) (port 8080, `--port` ou `PORT`), MIME wasm/js/json, Range, liste blanche des fichiers publics, protection contre `../`, refus (403) des liens symboliques qui sortent de la racine (realpath ; pour `roms/` et `bios/`, de leur propre realpath, donc liables vers un autre disque ; T23 : `roms/` et `bios/` servis depuis `romsDir` et `biosDir`, tests `tests/serve-dossiers.test.mjs`), `X-Content-Type-Options: nosniff` partout. Tests : `tests/serve*.test.mjs`.
- `local-settings.mjs` : lit et valide `clone90.local.json` (`romsDir`, `biosDir`, chemins absolus existants, sinon avertissement et repli sur `roms/` et `bios/`), partagé par `generate-games.mjs` et `serve.mjs` ; `node scripts/local-settings.mjs show|set` (T23). Tests : `tests/local-settings.test.mjs`.
- `settings-api.mjs` : API locale des dossiers (T25) : `GET /api/settings`, `POST /api/settings/choose`. Active seulement en écoute locale sous macOS ; contrôles Host, Origin ou `X-Clone90`, JSON, 1 Ko, verrou ; aucun chemin ne vient du navigateur. Réutilise `local-settings.mjs` et `generate-games.mjs`. Tests : `tests/settings-api.test.mjs`.
- `mac-folder-dialog.mjs` : boîte « choisir un dossier » du Mac par osascript (`chooseFolderOnMac`, `buildAppleScript`), annulation = `null` (T25).
- `project-root.mjs` : constante `PROJECT_ROOT` partagée par les scripts.
- `generate-games.mjs` : scanne `roms/<machine>/` d'après `systems.json` et écrit `games.json` (`--check` pour un simple diagnostic). Tri des titres via `js/sort.js` (partagé avec le navigateur). Fonctions pures exportées (`cleanTitle`, `makeId`, `resolveTitle`, `parseM3u`, `buildSystemGames`, `parseDiskTag`, `parseLooseDiskTag`) ; racine via `project-root.mjs`. Tests : `tests/generate-games.test.mjs`.
- `css-colors.mjs` : lecture des couleurs de `css/base.css` et contraste WCAG (`readCssColors`, `contrastRatio`, `hexToRgb`), partagés par les générateurs et `tests/design.test.mjs`.
- `generate-logos.mjs` : génère `assets/logos/<id>.svg` (nom en lettres pixel sur la couleur d'accent, forme géométrique) d'après `systems.json` et `css/base.css` (texte blanc `--text`, refus sous 4.5:1). À relancer quand une machine ou une couleur change ; `pixel-font.mjs` est la police 5x7 partagée.
- `generate-icons.mjs` : génère les icônes PWA `assets/icons/icon-*.png` (PNG fait maison, sans dépendance). Couleurs lues dans `css/base.css` (`--bg`, `--accent`). À relancer pour changer le dessin ou la palette.
- `build-mac-app.sh` : reconstruit `Clone90.app` (racine, commitée) depuis `mac-app/Clone90.applescript` avec `osacompile -s` (applet « stay open »), icône tirée de `assets/icons/icon-512.png`, signature ad hoc (T26). Ne lance rien. Tests : `tests/mac-app.test.mjs`.
- `mac-app/Clone90.applescript` : source lisible de l'application Mac (Node.js, `generate-games`, `serve --host 127.0.0.1` en arrière-plan, journal `~/Library/Logs/Clone90.log`, arrêt du serveur par pid à la fermeture). Jamais servie par `serve.mjs`.
